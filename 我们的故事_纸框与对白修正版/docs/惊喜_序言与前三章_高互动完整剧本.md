# 《惊喜》高互动重制版

**范围：序言与前三章，故事止于当天 12:40。**

本文件记录分支剧情与后果。原画风运行版另外保留校园到城市的开场动画，并在 A 的工作视角加入前一晚出租屋的短回忆演出；回忆不改变当前游戏事实时间。所有节点仍使用原画内字幕、气泡、人物动作与选择弹窗。

版本 3.0.0。本文与可运行游戏的 story.js 同步生成。动态场景展示一组可达状态下的台词；同一选项受先前经历影响的其他后果也列出。阶段结局是这一刻的状态，不代表关系最终结局。

## 这一版的互动结构

- 共 21 个决策节点、63 个选项，每轮实际经历 14—16 次决定。
- 每个节点先呈现 1—3 句剧情，立刻暂停给玩家选择；选择后先看专属后果，再继续。
- 三条中段路线分别是当面见面、语音沟通、前台交接，每条都有独立场景和后续选择。
- 行动、消息草稿、安排三种参与方式；可查看物件获取额外信息，有些线索会解锁选项。
- 饭盒归属、已说出的信息、留下或离开的安排会持续带入后文。没有好感分或正确答案。
- 可在“你走过的路”回到任一决定。后续经历清空，重新选择；发送确认和继续按钮不算新增决策。
