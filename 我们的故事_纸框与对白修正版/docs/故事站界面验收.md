# 故事站界面与游戏接入验收

日期：2026-10-25。

## 范围和来源

以本次提供的 `our-stories-source.zip` 为首页参考，复用其白粉撕纸版式、双人拼贴主视觉、卡片、文字故事编辑与本机存储模型。素材放入 `dist/assets/portal`，首页脚本与游戏脚本分开加载，避免同名样式影响舞台。

首页 `index.html` 主按钮保持原文“看看我们的故事”及原去向；下方案例卡片《惊喜》实际进入 `play.html`。游戏保留13幕完整一天主线、26个决策节点、78个选项和原绘本背景动画。游戏内部采用白粉纸张边框、纸签、字幕、选择卡和按钮，返回入口定位到故事列表。

文字故事保存到当前浏览器，不接入账户、云端或支付。空卡片明确标注待添加；商城保持正在准备中。

## 对白与纸张边框修正

使用同一句“我在你公司对面，给你带了饭。你现在方便说话吗？”复查。原气泡受人物容器的绝对定位自动宽度影响，桌面宽约94px；改为整句测量后宽320px、高85px，逐字显示期间保留完整尺寸。

实际播放器临时验收页检查左右角色和靠边角色；390×844视口中，294px气泡距舞台左右边缘各约16px，文字完整。角色图片加载和视口变化后重新计算定位。场景纸签的计算样式 `backdrop-filter` 为 `none`，不再叠加毛玻璃虚化层。临时按钮与测试页未包含在发布文件中。
