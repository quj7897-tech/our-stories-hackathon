# 《惊喜》分支与结局速览

游戏在每个决策处暂停，选后先给后果，再进入下一幕。所有路径止于 12:40；以下结局描述此刻的安排，未提前演出午后是否兑现、和好或分开。

## 前半段怎样分开

|阶段|决定|持续影响|
|---|---|---|
|序言 P1|想一起吃饭／想感到他也期待／送饭并了解近况|后面真正表达需要时，台词会引用你选的来意；最初只是一句心里话|
|序言 P2|便签／照片／保温包装|便签可以被读到，照片可以提前发，保温准备会在见面回调|
|途中 C1_TRAVEL|预告到访／只发照片／保留惊喜|A 提前收到的信息不同，尚不等于约好见面|
|到达 C1_CONTACT|明确位置／打电话／试探“在吗”|“在吗”额外进入 C1_SILENCE，可补充信息、先吃东西或打电话|
|工作 C2_WORK|核图／写结论／请同事协作|改变 A 剩余任务与会议提前时的反馈；先看待办才能确认同事提供了帮助|
|路线 C2_ROUTE|见面／通话／前台方案|真正进入下面三组互斥场景|

## 三条独立场景路线

|路线|第一个专属暂停|第二个专属暂停|带入后文的事实|
|---|---|---|---|
|当面见面 M1 → M2|A 先欢迎、解释工作或询问安排|B 交饭并说来意、交饭暂不展开，或留着想一起吃|是否见面、饭盒是否交给 A、便签是否被读到、来意是否说出|
|电话两端 V1 → V2|A 说清限制、主动听，或只请她等|B 说需要、约定更新，或只谈饭盒|只通了话；饭盒仍由 B 持有；具体传达的信息有所区别|
|前台安排 F1 → F2|B 确认代收、继续拿着，或想亲手交|A 回应心意、只确认物流，或询问 B 的安排|前台必须明确确认才算收下；提出前台方案不等于自动交接|

三条路线在会议提前后进入共同情境，但对白读取此前发生的事。未曾说出的期待不会自动成为 A 已知的信息。

## 第三章的连续暂停

1. **C3_UPDATE** 会议提前。A 要说明真实时间、笼统说很快，还是打电话交代。
2. **C3_FEEL** B 要说失落与需要、追问时间，还是暂不展开。
3. **C3_REPLY** A 如何回应 B 实际说过的话。
4. **C3_PLAN** B 自己决定留到 13:00、留到 15:00，或现在离开。
5. **C3_WAIT / C3_LEAVE** 留下的人决定吃东西、休息或看手机；离开的人决定后续联系方式。
6. **C3_BOX（条件节点）** 准备离开且饭盒仍由 B 持有时，决定确认寄存、带走并告知，或带走暂不补充。
7. **C3_ACK** A 进会前准确确认、只说收到，或暂不回复，随后呈现阶段结局。

## 每类路径对应哪个结局

|B 的决定|中段路线／饭盒状态|A 最后怎样回应|12:40 的结局|
|---|---|---|---|
|留到 13:00 或 15:00|当面见面|准确确认期限和位置|**E_MEET_WAIT · 见过一面，还留着一段时间**|
|留到 13:00 或 15:00|电话两端|准确确认期限和位置|**E_VOICE_WAIT · 声音接上了，见面还没发生**|
|留到 13:00 或 15:00|前台安排，可已交接或仍保留饭盒|准确确认期限和位置|**E_DESK_WAIT · 饭盒的去处，和人的去处**|
|留到 13:00 或 15:00|任意中段路线|只说收到，或暂不回复|**E_WAIT_UNCONFIRMED · 我说了期限，你还没有接住**|
|离开|饭盒已交给 A，或前台已确认代收|任一回应；结局内保留回应差别|**E_LEFT_DELIVERED · 人先离开，午饭留下**|
|离开|饭盒随 B 带走|任一回应；结局内保留回应差别|**E_LEFT_BOX · 把饭盒带走，把话留给以后**|

这张表穷尽程序的结局判断规则，但不把每组选择组合冒称成一个独立结局。相同阶段结局里，来意是否被传达、饭盒去处是否同步、此前后续联系承诺等事实仍可能不同。
