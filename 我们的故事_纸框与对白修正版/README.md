# 我们的故事 · 《惊喜》完整一天修正版

修复上一份交接包止于12:40的范围错误：以原来的13幕完整故事为主线，保留高互动版前半段21个决策节点，接回会议、保温盒、归途、追赶、站台与20:00尾声。

## 开始游玩

Windows双击 `开始游戏.bat`，需要Node.js或Python 3中的一种，不需要Godot。也可在本目录运行 `node server.cjs --open` 或 `python server.py --open`；macOS可运行 `bash 双击开始游戏.command`。

默认地址为 `http://127.0.0.1:8190`，端口被占用时以启动窗口打印的地址为准。保持启动窗口开启。首页标题为“我们的故事 · 从这里开始”，从下方“热门故事”的《惊喜》卡片进入游戏；主按钮保留原文“看看我们的故事”及原去向。也可直接访问 `/play.html`。不要只双击HTML文件，Godot运行文件需要本地HTTP服务。

首页沿用本次提供的 `our-stories-source.zip` 白粉撕纸版式。“我的故事”支持在本机保存文字草稿、预览和导出JSON；这些内容只存在当前浏览器中。另两张卡片标注“待添加剧本”，商城标注“正在准备中”。

- **开始故事**：从校园序章开始，经历全部选择。
- **直接体验下午剧情**：通过真实重放上午选择建立示例路线，进入会议之后。示例中已当面交接饭盒，可从经历按钮返回上午重选。
- 点字幕先补全文字，再点继续；自动播放不会替玩家选择。
- 上一步和经历按钮支持回退，之后的交接、邀请、回应及结局会撤销。

## 修正内容

1. 12:40的六种结果变成中途检查点，继续到当天20:00。当前33个剧情节点，其中26个决策节点、78个选项，单轮一般19—21次决定。
2. 饭盒保持唯一归属。已当面交给A时不会重复留前台；没有交出时不会凭空出现在前台；明确领取后才从前台交给A。
3. 站台见面需要B明确愿意，也可以约晚饭后通话或明天联系。需要空间的路线不强行追赶或和好。
4. 根据位移修正朝向，并修复Godot镜像导致的横向偏移。行走、挥手、点头、倾听、思考、看消息、惊讶、疲惫和情绪反应使用同一剧情时钟，暂停与倍速同步。
5. 接入此前确认的8张奶黄、青绿、淡紫与蜡笔绘本背景。窗景、吊环、晃动、会议图表、街景滚动和原回想效果继续工作。校园、厨房、便利店、尾声保留原空间和道具。
6. Godot继续实际绘制角色，透明画布保留网页的动态背景。字幕、选择、消息、思想和回想气泡沿用原流程。引擎加载失败时保留网页画面。
7. 修复自动演出结束时，选择面板的淡入动画被场景暂停样式冻结在透明状态的问题。角色和背景仍按剧情时钟暂停，选择与“继续故事”正常显示。
8. 游戏内部套用白粉纸张边框、纸签、字幕、选择卡与按钮样式。对白宽度独立于人物尺寸，按整句预留空间，手机与图片加载后重新定位；场景标题取消毛玻璃，避免模糊残留。

动作基于原32张真实角色帧和局部姿态组合，没有新增完整骨骼或跑步原画。追赶使用更快的行走帧和步伐。

## 交接文件

- `dist/index.html`、`portal.js`、`styles.css`、`gentle.css`、`portal-tweaks.css`：故事站首页与本机文字故事编辑。
- `dist/play.html`、`game-shell.css`：完整游戏入口及与首页一致的外层界面。
- `dist/story.js`：保留的前半段21个决策节点。
- `dist/full-day.js`：下午分支、完整结局、事实延续和下午体验入口。
- `dist/engine.js`：选择、后果、检查点推进和回退。
- `dist/cinematic-scenes.js`、`full-day-scenes.js`：原演出和按事实调整的下午演出。
- `dist/cinema.js`、`motion.js`：字幕、动作、移动和环境时钟。
- `dist/scene-art.js`、`art-motion.css`、`assets/backgrounds`：背景风格与动态层组合。
- `godot`：可编辑引擎工程，导出文件已在 `dist/godot`。

无需重新构建即可游玩。若修改引擎，使用Godot 4.7.2和对应Web单线程模板，运行 `tools/build-web.ps1 -Editor 编辑器路径 -WebTemplate 模板路径`。脚本不将本机模板路径留在工程中。
